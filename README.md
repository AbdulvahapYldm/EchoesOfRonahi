# Echoes of Ronahi

A solo-developed **Unreal Engine 5.8** third-person Action RPG. **Echoes of Ronahi** is a portfolio project focused on building scalable gameplay systems, clean C++ architecture, and data-driven RPG mechanics. The goal of this project is to demonstrate the system design, modular code structure, and gameplay programming skills expected of a professional Unreal Engine developer.

---

## Project Information

- **Game Engine:** Unreal Engine 5.8
- **Language:** C++ & Blueprint
- **Genre:** Third-Person Action RPG
- **Platform:** PC
- **Project Type:** Solo Portfolio Project

---

## Project Goals

The purpose of this project is to demonstrate professional Unreal Engine development practices through modular gameplay systems.

Focus areas include:
- Scalable combat and ability architecture built with the Gameplay Ability System (GAS)
- Data-driven, extensible inventory and equipment systems
- Modular, component-based C++ architecture
- Advanced UI programming (inventory, equipment preview, HUD)
- Clean, maintainable, and extensible system design
